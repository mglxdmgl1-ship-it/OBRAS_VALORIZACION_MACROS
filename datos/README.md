# Datos exportados

Una carpeta por obra (nombre corto). Cada valorización mensual se exporta a `valorizacion_NN_AAAA-MM.json` con `herramientas/exportar_valorizacion_json.py`. Estructura descrita en [docs/02_MODELO_DE_DATOS.md](../docs/02_MODELO_DE_DATOS.md).

| Archivo | Obra | Periodo |
|---|---|---|
| `iei881/valorizacion_01_2026-10.json` | I.E.I. N° 881 Miraflores – Cabanilla (CUI 2649805) | Valorización N° 01, 15/10/2026 – 31/10/2026 |

Los JSON no incluyen DNI ni celulares.
